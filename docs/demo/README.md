# Local report demonstration

`firstvisit-lab-demo.pdf` is a source-based demonstration report, published with the
source owner's explicit permission. Direct identity areas, clinician/facility details
and exact dates have been omitted. The source's actual results, units, reference
ranges and flags are retained; this is not a synthetic or guaranteed anonymous record.
The original report is not included.

In FirstVisit, create a task, choose **Add lab PDF**, select this file, review each
extracted row and confirm. A report remains optional for every starting point.
Importing this sample does not create diagnoses, medical recommendations or orders.
